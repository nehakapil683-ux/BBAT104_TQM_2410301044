# CRITICAL TO QUALITY (CTQ) TREE

## Project

Restaurant Billing System – Q05: Reduce Response Time

---

## Customer Requirement

Fast and responsive restaurant billing operations.

### CTQ 1 – Fast Search

Customer Need:
Find menu items quickly.

Measure:
Search response time.

Target:
Search results should appear quickly for normal-sized datasets.

---

### CTQ 2 – Quick Navigation

Customer Need:
Move between system modules without unnecessary steps.

Measure:
Number of navigation actions required.

Target:
Common modules should be accessible directly from the main navigation.

---

### CTQ 3 – Cached Dashboard

Customer Need:
Dashboard information should load quickly.

Measure:
Dashboard loading time.

Target:
Repeated dashboard requests should avoid unnecessary recalculation.

---

### CTQ 4 – Database Indexing

Customer Need:
Database searches should be efficient.

Measure:
Database query execution time.

Target:
Frequently searched fields should use appropriate database indexes.

---

### CTQ 5 – Paginated Reports

Customer Need:
Reports should not become slow when many records exist.

Measure:
Report page loading time.

Target:
Only a limited number of records should be loaded per page.

---

## CTQ Summary

| Customer Need | CTQ | Measurement |
|---|---|---|
| Fast menu search | Fast Search | Search response time |
| Easy system movement | Quick Navigation | Navigation steps |
| Fast dashboard | Cached Dashboard | Dashboard load time |
| Fast database access | DB Indexing | Query execution time |
| Fast reports | Paginated Reports | Page load time |
